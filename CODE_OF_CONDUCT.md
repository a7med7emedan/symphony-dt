# Code of conduct

This project adopts the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1.

We want a respectful, harassment-free community for everyone. Be kind, assume good faith, and critique ideas, not
people. Report unacceptable behaviour privately to the maintainer through the contact on the GitHub profile of
@a7med7emedan. Reports are handled confidentially.
