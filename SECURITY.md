# Security policy

## Supported versions

| version | supported |
|---|---|
| 2.x | yes |
| 1.x | no |

## Reporting a vulnerability

Please report security issues privately through GitHub's
[private vulnerability reporting](https://github.com/a7med7emedan/symphony-dt/security/advisories/new).
Do not open a public issue. You will receive an acknowledgement within seven days.

If you find participant data, an identifier or a restricted result in this repository, report it the same way.
